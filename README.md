# TRIPORA — Сервис поиска вдохновляющих путешествий

Премиальный демонстрационный сайт туристической компании **TRIPORA**, созданный на **HTML5**, **CSS3** и чистом **JavaScript (Vanilla JS)** без использования сторонних фреймворков, библиотек или сборщиков.

## Дизайн и палитра
- **Светлый премиальный интерфейс:** Молочные (`#faf8f5`, `#ffffff`) и тёплые песочные оттенки (`#efebe2`, `#f5f2eb`).
- **Бирюзовые и морские акценты:** Глубокий бирюзовый (`#0d9488`), морская пена (`#14b8a6`, `#f0fdfa`).
- **Контрастная типографика:** Насыщенный угольно-сланцевый цвет текста (`#182026`, `#475569`) со строгой иерархией.
- **Векторная живописная графика:** Тематические панорамы морей, гор, фьордов и восточных городов на чистом SVG без риска битых внешних изображений.

## Разделы сайта
1. **Главная страница:**
   - Выразительный Hero-блок с приветственным слоганом.
   - Полнофункциональная поисковая панель: выбор направления, даты, количества путешественников и типа отдыха.
   - Быстрые теги для мгновенного подбора (Пляжи, Альпы, Древняя культура, Фьорды, Велнес).
2. **Каталог направлений:**
   - 12 полноценных демонстрационных туров.
   - Живой поиск по названию и стране.
   - Фильтры по 5 категориям (*Пляжи и острова*, *Горы и треккинг*, *Культура и история*, *Приключения и природа*, *Экзотика и велнес*).
   - Фильтр по длительности (*до 6 дней*, *7–9 дней*, *10+ дней*).
   - Сортировка (*по популярности*, *сначала недорогие*, *сначала премиальные*, *по длительности*).
   - Состояние пустой выдачи с кнопкой сброса фильтров.
3. **Подробная страница направления (модальный лист):**
   - Панорамная иллюстрация.
   - Детальное описание и лучшие сезоны для посещения.
   - Поэтапная программа тура по дням (Day-by-Day Itinerary).
   - Перечень включенных услуг (отели, трансферы, экскурсии, гид).
   - Кнопка добавления/удаления из избранного.
   - Кнопка бронирования с честным уведомлением о демонстрационном режиме.
4. **Избранное (с сохранением в `localStorage`):**
   - Интерактивные сердечки на каждой карточке.
   - Динамический счетчик в главном меню (`Избранное 2`).
   - Отдельный экран со списком сохраненных туров.
   - Состояние пустого списка с возможностью перехода в каталог.
   - Данные сохраняются при перезагрузке страницы.
5. **О сервисе и стандарты качества:**
   - 4 принципа TRIPORA (Проверенные отели, Финансовая прозрачность, Поддержка 24/7, Небанальные локации).
6. **Контакты и форма подбора:**
   - Демонстрационные контакты (телефон, email, офис в Москве).
   - Форма запроса на подбор тура с валидацией имени и контактов.
   - Всплывающие уведомления (Toasts).

## Как запустить проект

### Вариант 1: Через VS Code Live Server (Рекомендуется)
1. Откройте директорию проекта в **VS Code**.
2. Убедитесь, что установлено расширение **Live Server**.
3. Нажмите правой кнопкой мыши на `index.html` и выберите **«Open with Live Server»**.
4. Сайт откроется в браузере по адресу `http://127.0.0.1:5500/index.html`.

### Вариант 2: Прямое открытие в браузере
Поскольку проект не требует сборщиков и сервера, просто дважды кликните по файлу `index.html` в проводнике (Windows Explorer / macOS Finder) — сайт откроется в вашем браузере по умолчанию.

### Вариант 3: Любой локальный HTTP-сервер
```bash
# Через Node.js npx
npx serve .

# Либо через Python 3
python3 -m http.server 8000
```
Затем перейдите по адресу `http://localhost:8000`.
